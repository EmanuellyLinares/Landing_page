MovieCity é um projeto de desenvolvimento web criado com React, com o objetivo de apresentar uma página inicial para exploração de filmes. O projeto possui uma interface moderna, com tema escuro, cards com pôsteres e um cabeçalho com opções de navegação.

📌 Funcionalidades

Cabeçalho: exibe a identidade visual do MovieCity.

Menu de navegação: apresenta as opções Filmes, Categoria, Sobre e Contato.

Botão Login: disponibiliza um botão de acesso à área de login.

Apresentação inicial: contém um título, uma descrição e um botão para explorar filmes.

Cards de filmes: apresenta pôsteres de filmes e produções audiovisuais.

Menu responsivo: possui um menu hambúrguer para dispositivos menores.

Layout responsivo: adapta a disposição dos elementos conforme o tamanho da tela.
